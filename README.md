# CoD-MiCo
**Co-design of Mixed-Compression RISC-V Extensions for Neural Networks on FPGAs**

> ⚠️ **This is a placeholder repository.**
> The source code is planned to be published in **early 2027**.

## About

CoD-MiCo is a hardware–software co-design framework that jointly explores neural network compression and custom RISC-V instruction-set extensions for efficient inference on FPGAs.
